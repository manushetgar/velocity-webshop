How it works

  1. Upload your file here – CSV, Excel, JSON or XML, with your own column names.
  2. VeloCity translates it with the format agreed with you and checks every line.
  3. New products, prices and stock are written into VeloCity's SAP ERP and appear in the web shop.
  4. You get an acknowledgement for every file – here and in your FTP /outbox.
